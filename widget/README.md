# Embeddable 2027 COLA tracker

Copy the iframe from [`embed-example.html`](embed-example.html), or use the guided version at [COLA Insight](https://www.colainsight.com/2027-cola-widget).

The widget is read-only and updates from the same stored record as the live forecast page. Keep its COLA Insight source link visible. Do not present a forecast or computed value as an official SSA announcement, and do not imply government endorsement.
