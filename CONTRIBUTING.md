# Contributing

Corrections to source labels, field definitions, examples, accessibility, and documentation are welcome.

For a data correction, include:

1. the affected file and field;
2. the value currently shown;
3. the proposed value;
4. a link to the responsible primary source;
5. the publication or observation date.

Please do not submit speculative values as official data. Forecasts, formula-derived results, and official SSA determinations must remain clearly separated.

Security issues should not be placed in a public issue. Email [support@colainsight.com](mailto:support@colainsight.com).
